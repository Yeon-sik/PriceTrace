# 표준 상품 연결 예외 — 현재 미연결 상품

최종 정리일: 2026-08-05

이 문서는 **공식 상품 후보를 승인 대기열에 넣을 수 없는 현재 예외만** 기록한다.

- 관리자 승인 대기열에 저장된 상품은 제외한다. 대기열 저장은 DB 연결 완료가 아니지만, 더 이상 조사 예외는 아니다.
- 이미 등록된 중복 상품과 같은 공식 상품의 반복 영수증 관측은 제외한다.
- 같은 물품번호의 반복 관측은 한 항목으로 합친다.
- 이름 유사도 85% 이상은 검토 후보를 열어 주는 탐색 기준이다. 영수증명이 공식명 안에서 85% 이상 일치하는 경우도 포함한다. 유일 후보, exact variant, 규격, 브랜드·제조사 근거가 닫히지 않으면 연결하지 않는다.
- 쿠팡 옵션 부재만으로 제외하지 않는다. 공식 상품과 exact variant를 1차 근거로 확인할 수 있으면 `link_only_v1` 제안 대상이 될 수 있다.
